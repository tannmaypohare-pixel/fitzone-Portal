# FitZone Portal 🏋️‍♂️

FitZone Portal is a full-stack Gym Management System designed to simplify gym operations by managing members, trainers, memberships, payments, and reports through a modern web dashboard.

The system provides an admin panel for gym owners to manage daily activities efficiently and maintain organized member records.

---

## 🚀 Features

### 🔐 Authentication
- User registration and login
- JWT-based authentication
- Role-based access control
- Protected routes
- Password reset system
- Google OAuth integration (in progress)

### 👥 Member Management
- Add new members
- Update member details
- Delete members
- View member profiles
- Track membership status
- Manage expiry dates
- Membership renewal support

### 🏋️ Trainer Management
- Add trainers
- Manage trainer information
- Assign trainers to gym operations

### 💳 Membership Plans
- Create membership plans
- Edit plans
- Delete plans
- Display available plans
- Manage pricing and duration

### 💰 Payments
- Record payments
- Track revenue
- View payment history
- Connect payments with memberships

### 📊 Dashboard & Reports
- Live dashboard statistics
- Total members tracking
- Active/expired membership tracking
- Revenue analytics
- Member growth reports
- Plan-based reports
